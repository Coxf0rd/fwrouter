# `installer/safe_recovery.py`

Prepares, verifies and stages a hosted-qualified backend artifact only into a private temporary target. Its source manifest includes the exact tracked backend tree and the installer execution closure required by backend deployment: `install.sh`, `obsolete-backend-paths.txt` and `component_install_lock.py`. Preparation rejects missing/dirty inputs; artifact verification requires the same required paths and binds their file hashes and modes to the archive. Staging extracts only verified entries and invokes that included installer with `--deploy --component backend --target`, then checks installed backend hashes and retained extras. This is isolated rehearsal, not live restore, database recovery or runtime rollback. Hosted receipts are supplied evidence and are not independently authenticated by this tool.
