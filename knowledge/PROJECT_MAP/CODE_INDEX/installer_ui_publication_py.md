# `installer/ui_publication.py`

Publishes the FWRouter UI into immutable content-addressed release directories and atomically switches `/opt/fwrouter-ui` with Linux `renameat2(RENAME_EXCHANGE)`. It verifies the installed backend against the trusted source backend using the canonical filtered manifest in `controlled_backend_lifecycle.py`, serializes publishers with an invoking-identity-owned mode-`0600` lock, validates path ancestry, ownership, web-server-readable modes, symlink-free content and bounded size/count, fsyncs candidate data and both sides of archival renames, and retains the complete previous tree on interruption or postflight failure. Live publication requires root-owned source/installed trees; `--target` uses disposable invoking-user-owned paths. Called only by `installer/install.sh` for the UI component.
