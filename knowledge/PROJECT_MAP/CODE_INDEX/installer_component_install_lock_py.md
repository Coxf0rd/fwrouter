# `installer/component_install_lock.py`

Provides the shared per-target serialization boundary for cooperating `install.sh` backend/UI operations and direct UI publication. It validates the target `/opt` path and lock file without following symlinks, opens a mode-`0600` lock, and execs the installer with the locked descriptor inherited. The installer validates the descriptor against the exact target lock before mutations. Direct `ui_publication.py` calls acquire the same lock before the UI-specific publication lock. Backend/UI/`--all` installer calls hold it through bootstrap and any final UI compatibility check/exchange. The separate controlled-backend-lifecycle CLI lock is not held during installer execution. This contract serializes cooperating project installers; it does not fence privileged writes performed outside those paths.
