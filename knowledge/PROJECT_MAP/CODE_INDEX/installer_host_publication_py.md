# `installer/host_publication.py`

Implements the fixed `fwrouter-host-publication-plan/v1` executor used only by `install.sh --deploy --component host --host-plan`. The v1 allowlist contains the boot preflight helper and API unit; plans may select a nonempty subset and must preserve helper-before-unit order when both are selected. It validates bounded duplicate-free private plan JSON, fixed source/target paths and modes, source digests, and target compare-and-swap digests. Directory traversal and file opens use no-follow descriptors; each file is staged in its destination directory, fsynced, atomically replaced, and read back. The operation is atomic per file, not across files. A rerun accepts only already-desired bytes/mode from the exact supplied old/new plan and continues only where the remaining target still matches its old digest or absence. Equal old/new digests permit a CAS-protected fixed-mode correction.

The CLI requires and verifies the inherited exclusive component-install lock. The installer acquires that common component lock first, then the existing host maintenance lease, which also requires backend writer units quiescent on the live root. The lease remains held for the complete operation. This serializes cooperating FWRouter installers; privileged writes outside that contract are not fenced. Before the first write, the helper validates every selected destination path and its CAS state; it then repeats per-file checks immediately before replacement. The helper does not copy other host files, bootstrap state, change `.env` permissions, run systemd actions, or prove compatibility between the API unit and installed backend. See [`installer/README.md`](../../../installer/README.md#selective-host-publication) and regression tests in `installer/tests/test_host_publication.py`.
